# راه‌اندازی سرور PhantomArt

دو راه دارید:

| | راه ۱: Cloudflare Worker | راه ۲: سرور مجازی (VPS) |
|---|---|---|
| هزینه | **رایگان** | حدود ۴ دلار در ماه (یا Oracle رایگان) |
| نیازمندی | فقط یک ایمیل | کارت بانکی خارجی |
| سختی | آسان (کپی و پیست) | آسان (یک دستور) |
| کیفیت | مناسب وب‌گردی، تلگرام، یوتیوب | بهترین و پایدارترین |
| محدودیت | ۱۰۰ هزار درخواست در روز، بدون UDP (تماس صوتی/بازی) | ندارد |

پیشنهاد: با **راه ۱** شروع کنید. هر وقت VPS گرفتید، راه ۲ را هم اضافه کنید.

## راه ۱: سرور رایگان روی Cloudflare

### گام ۱: ساخت حساب Cloudflare
1. به سایت https://dash.cloudflare.com/sign-up بروید.
2. ایمیل و یک رمز وارد کنید و ثبت‌نام کنید. ایمیل تأیید را باز کنید و روی لینکش بزنید.

### گام ۲: ساختن کلید مخفی (UUID)
1. به https://www.uuidgenerator.net بروید.
2. کدی که نشان می‌دهد (شبیه `3f2a9c1e-7b4d-4e8a-9f21-0c6d5b8a7e13`) را کپی کنید و جایی **یادداشت کنید**.
   این رمز سرور شماست؛ به کسی ندهید.

### گام ۳: ساختن Worker
1. در داشبورد Cloudflare از منوی سمت چپ **Compute (Workers)** و بعد **Workers & Pages** را بزنید.
2. دکمه‌ی **Create** را بزنید، بعد **Start with Hello World!** (یا **Create Worker**).
3. یک اسم بدهید (مثلاً `my-site-123`؛ بهتر است اسمی معمولی باشد، نه vpn) و **Deploy** را بزنید.
4. روی **Edit code** بزنید.
5. همه‌ی کدهای داخل ویرایشگر را پاک کنید (Ctrl+A و بعد Delete).
6. فایل [`cloudflare-worker/worker.js`](cloudflare-worker/worker.js) را باز کنید، دکمه‌ی **Raw** را بزنید،
   همه را کپی کنید (Ctrl+A، Ctrl+C) و داخل ویرایشگر Cloudflare پیست کنید (Ctrl+V).
7. دکمه‌ی **Deploy** (بالا سمت راست) را بزنید.

### گام ۴: وارد کردن UUID
1. به صفحه‌ی Worker برگردید و تب **Settings** را باز کنید.
2. در بخش **Variables and Secrets** روی **Add** بزنید.
3. Type را روی **Secret** بگذارید، در Variable name بنویسید `UUID` و در Value همان کدی که در گام ۲ یادداشت کردید را بگذارید.
4. **Deploy** را بزنید.

### گام ۵: گرفتن لینک کانفیگ
1. در صفحه‌ی Worker (تب **Overview**) آدرس آن را می‌بینید؛ شبیه `my-site-123.damoon-ahmady.workers.dev`.
   **همان آدرس را دقیقاً کپی کنید** (بخش وسط آن، نام کاربری حساب Cloudflare شماست و برای هر کس فرق دارد).
2. در انتهای آن یک `/` و بعد UUID خودتان را اضافه کنید و در مرورگر باز کنید. مثال:
   ```
   https://my-site-123.damoon-ahmady.workers.dev/3f2a9c1e-7b4d-4e8a-9f21-0c6d5b8a7e13
   ```
   - اگر خطای `ERR_NAME_NOT_RESOLVED` دیدید: آدرس را اشتباه تایپ کرده‌اید؛ دوباره از صفحه‌ی Overview کپی کنید.
   - اگر «It works!» دیدید: UUID اشتباه است.
   - اگر «Server is not configured» دیدید: متغیر UUID (گام ۴) ذخیره نشده است.
   > این صفحه را از ایران ممکن است فقط با یک فیلترشکن دیگر بتوانید باز کنید (چون دامنه‌ی workers.dev فیلتر است). فقط برای همین یک‌بار.
3. صفحه‌ای با لینک‌های کانفیگ نشان داده می‌شود. **لینک سابسکریپشن** را کپی کنید.
4. در PhantomArt به تب «سابسکریپشن» بروید، لینک را پیست کنید و «افزودن» را بزنید.

### گام ۶: اتصال
1. در تنظیمات PhantomArt مطمئن شوید تیک **«فرگمنت (Fragment)»** روشن است (پیش‌فرض روشن است).
   این گزینه کمک می‌کند فیلتر دامنه‌ی workers.dev دور زده شود.
2. سرور را انتخاب و دکمه‌ی پاور را بزنید، بعد «تست اتصال».

### اگر وصل نشد
فیلترینگ ایران مدام تغییر می‌کند. به‌ترتیب امتحان کنید:
1. **IP تمیز:** در اینترنت «Cloudflare clean IP» برای اپراتور خودتان (همراه اول، ایرانسل، مخابرات) را جست‌وجو کنید.
   چند IP پیدا کنید و در تنظیمات Worker یک متغیر دیگر بسازید: نام `CLEAN_IPS`، مقدار مثلاً `104.16.1.1,172.67.2.2`.
   دوباره Deploy کنید و در PhantomArt «به‌روزرسانی همه» را بزنید. حالا برای هر IP یک سرور جدا دارید؛ «پینگ همه» را بزنید و سریع‌ترین را انتخاب کنید.
2. **دامنه‌ی شخصی:** اگر یک دامنه دارید، آن را به Cloudflare اضافه کنید و در Worker از
   **Settings → Domains & Routes → Add → Custom domain** وصلش کنید. دامنه‌های شخصی خیلی کمتر از workers.dev فیلتر می‌شوند.
3. **سایت‌هایی که پشت Cloudflare هستند باز نمی‌شوند؟** این محدودیت Workers است. یک متغیر `PROXYIP` بسازید
   و یک «proxy IP» عمومی (با جست‌وجوی «Cloudflare worker proxyip») در آن بگذارید.

## راه ۲: سرور مجازی (VPS) با VLESS + Reality

Reality سخت‌ترین پروتکل برای شناسایی توسط فیلترینگ است؛ ترافیک شما شبیه بازدید از سایت مایکروسافت دیده می‌شود.

### گام ۱: خرید VPS
- **سرور:** هر سرور **Ubuntu 22.04 یا 24.04** خارج از ایران (آلمان، هلند، فنلاند معمولاً خوب‌اند).
- **پیشنهادها:**
  - Hetzner، حدود ۴ یورو.
  - Oracle Cloud Free Tier، رایگان ولی ثبت‌نامش سخت است.
  - فروشنده‌هایی که با کارت ایرانی/کریپتو VPS خارجی می‌فروشند.
- **آنچه بعد از خرید دریافت می‌کنید:** یک **IP**، نام کاربری **root** و یک **رمز**.

### گام ۲: وصل شدن به سرور
1. در ویندوز، **PowerShell** را باز کنید (در منوی Start بنویسید PowerShell).
2. این را بنویسید (IP خودتان را بگذارید) و Enter بزنید:
   ```
   ssh root@1.2.3.4
   ```
3. اگر پرسید `Are you sure...`، بنویسید `yes`. بعد رمز را وارد کنید. موقع تایپ رمز چیزی نمایش داده نمی‌شود؛ عادی است.

### گام ۳: نصب
این دستور را کپی کنید، در PowerShell راست‌کلیک کنید (پیست می‌شود) و Enter بزنید:
```
bash <(curl -fsSL https://raw.githubusercontent.com/damoonartwork/PhantomArt/claude/filter-breaker-app-hn2o05/server/vps/install.sh)
```
حدود یک دقیقه طول می‌کشد. در پایان یک لینک `vless://...` و یک QR کد نشان می‌دهد.

### گام ۴: اتصال
لینک `vless://...` را کپی کنید (با موس انتخاب کنید و راست‌کلیک) و در PhantomArt «افزودن از کلیپ‌بورد» را بزنید.

لینک گم شد؟ دوباره به سرور وصل شوید و بزنید:
```
cat /usr/local/etc/xray/phantomart-link.txt
```
